# 💳 Subscription Pricing Page

A frontend practice project built using HTML5 and CSS3 to create a subscription pricing page. It presents three subscription plans — Free, Standard, and Premium — allowing users to compare their available features through a simple pricing-card layout.

## 🌐 Live Demo

[![Live Demo](https://img.shields.io/badge/Live-Demo-orange?style=for-the-badge&logo=github)](https://inthusha20241647-commits.github.io/subscription-pricing-page/)

## ✨ Features

- 💳 **Pricing Plans:** Displays three subscription options: Free, Standard, and Premium.
- 📊 **Feature Comparison:** Shows the features available under each subscription plan.
- ✅ **Feature Indicators:** Uses tick and cross icons to distinguish included and unavailable features.
- 🎨 **Card Styling:** Uses CSS to style and organize individual pricing cards.
- 📱 **Responsive Layout:** Includes styling to adapt the page layout to different screen sizes.
- 🧭 **Structured Layout:** Organizes subscription details in a clear and easy-to-compare format.
